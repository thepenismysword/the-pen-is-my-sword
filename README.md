# The Pen Is My Sword — website & Killer Clicker wiki

A self-contained static website, designed for GitHub Pages.

## Preview locally
Open `index.html` in a browser. The links use relative paths so local navigation works.

## Publish on GitHub Pages (when approved)
1. Create a public GitHub repository, such as `the-pen-is-my-sword`.
2. Upload the contents of this folder to the repository root.
3. In Settings → Pages, select Deploy from a branch, `main`, `/ (root)`; save.
4. Visit the URL GitHub supplies. Your wiki lives under `/wiki/`.
5. When ready, configure your custom domain in GitHub Pages **before** changing DNS in Porkbun. Follow GitHub's current documentation.

No backend or database is required. The site is plain HTML and CSS.

## Before launch
- Replace playtest and album coming-soon notices with verified URLs.
- Verify wiki discrepancies identified at the end of `wiki/guide.html`.
- Review all wording and spoiler visibility.
- Confirm rights/credits for supplied artwork.
- Optionally optimize large PNG assets for faster mobile loading.

## Editing
Edit the HTML page files and `style.css`. Assets are in `assets/`.
